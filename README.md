## 🌟 개요

이 프로젝트는 **고린도전서 1장 10-17절** 설교 말씀을 시각적으로 정리한 **반응형 웹 인포그래픽**입니다.  
교회 내의 분열과 파벌 형성을 경계하고, 찢어진 그물을 깁듯(*카테르티스메노이*) 그리스도의 십자가 은혜 안에서 서로를 회복하고 온전히 연합하는 성도의 삶을 안내합니다.

## 📌 주요 인포그래픽 섹션 구성

1. **소그룹과 당파 — 무엇이 다른가?**
   - 건강한 소그룹(생명의 나눔, 환대, 이해) vs 분열을 낳는 당파(배타성, 험담, 기득권 '정치질')
2. **바울의 권면 — 찢어진 그물을 꿰매라 (*κατηρτισμένοι*)**
   - 갈등 덮어두기가 아닌, 직접 살피고 꿰매어 온전하게 바로잡는 회복의 원리
3. **사람의 이름이 아닌, 그리스도의 이름으로**
   - 바울파·아볼로파·게바파·그리스도파의 인간적 자랑 vs 오직 십자가 중심축
4. **분열의 상처 — "조용해졌다고 끝난 게 아닙니다"**
   - *목사님과 장로님의 눈빛 예화*: "말의 의도"보다 "상대방에게 전달된 태도와 상처"를 경청하기
   - *"제 뜻은 이랬습니다. 그런데 제 말이 어떻게 들리셨는지도 듣고 싶습니다."*
5. **십자가가 가려지면 교회가 아닙니다**
   - 25년 목회의 배움: 결과를 넘어 사람을 대하는 태도의 중요성
   - 섬기는 자로 오늘을 살기: 서로 기대어 서는 사람 인(人)의 공동체
6. **실천 가이드 & 인터랙티브 묵상 체크리스트**
   - 한 주간 관계를 다시 잇는 4가지 언어와 행동 실천
   - 로컬 브라우저 저장 가능한 묵상 메모장 탑재

## 💻 기능 및 특징

- 📱 **완전 반응형 디자인**: 모바일, 태블릿, 데스크톱 최적화
- 🌓 **다크 모드 / 라이트 모드**: 원클릭 테마 전환
- 🖨️ **인쇄 및 PDF 내보내기**: 설교 나눔지/인쇄용 CSS 최적화
- 💾 **로컬 묵상 노트**: 브라우저 로컬 스토리지에 나만의 결단 저장
- 🌐 **GitHub Pages 호환**: 별도 빌드 없이 즉시 호스팅 가능

## 🚀 배포 (GitHub Pages)

1. 저장소 `Settings` > `Pages` 메뉴로 이동합니다.
2. `Branch` 설정에서 `main` 브랜치를 선택하고 저장합니다.
3. 몇 초 후 제공되는 퍼블릭 URL로 인포그래픽을 전 세계 성도들과 공유할 수 있습니다.
